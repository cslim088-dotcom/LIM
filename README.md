# 🏛️ 무기고 (Arsenal) — 학생 배포용 에이전트 실습 키트

반갑습니다! 이 저장소는 여러분의 성장과 발전을 도울 **개인 AI 에이전트 협업 시스템 '무기고'**의 핵심 개념 실습 키트입니다. 

에이전트를 단순히 일회성 챗봇으로 사용하는 것에서 벗어나, 에이전트에게 **영혼(성격)**을 불어넣고, **역할 분담(조직)**을 가동하며, **특수 지식 가이드(스킬)**를 적재하여 협업하는 강력한 시스템 개발 방식을 학습하는 데에 도움이 되길 바랍니다.

---

## 💖 하네스(Harness)에 대한 감사와 경의

이 멋진 무기고 시스템의 기초가 되어준 **에이전트 하네스(Agent Harness)** 프레임워크와 개발진 여러분의 헌신과 오픈소스 정신에 진심 어린 감사를 표합니다. 하네스가 없었다면 에이전트와의 체계적인 협업과 자동화 도구들의 결합은 이토록 쉽고 강력하게 구현되지 못했을 것입니다. 개발자 생태계를 한 단계 진화시켜 준 하네스 팀에 깊은 고마움을 전합니다.

## 📂 저장소 구조 (Directory Structure)

본 실습용 무기고는 아래와 같은 군더더기 없고 직관적인 구조로 구성되어 있습니다.

```text
lee_main/
│
├── .agents/                 # 에이전트 전문 지식 및 스킬 저장소
│   └── skills/
│       └── basic-harness/   # 기본 스킬 템플릿
│           └── SKILL.md     # 스킬 필요성 및 작성법 설명서
│
├── .env.example             # 환경 변수 설정 템플릿 (API 키 관리용)
├── .gitignore               # 소스 코드 보안 관리 파일 (비밀키 유출 방지)
├── README.md                # 저장소 소개 및 가이드 (본 문서)
├── instruction.html         # 미려한 비주얼로 제작된 인터랙티브 설명서 웹페이지
│
├── soul.md                  # [실습] 에이전트 성격 및 행동 강령 템플릿
├── agent.md                 # [실습] 에이전트 로스터 및 역할 정의 템플릿
└── user.md                  # [실습] 사용자 개발 환경 및 코딩 스타일 정의 템플릿
```

## 🛠️ 핵심 개념 설명

무기고 시스템이 에이전트를 조율하는 3대 축과 특수 지식 공급 방식입니다.

1.  **`soul.md` (영혼/행동강령)**
    *   에이전트가 어떤 가치관과 태도를 가지고 행동할지 규칙을 세웁니다. 에이전트가 돌발 상황에서도 이 철학을 유지하며 작업에 임하도록 제어합니다.
2.  **`agent.md` (동료/조직)**
    *   여러 에이전트가 동시 혹은 병렬로 일할 때 각 에이전트의 R&R(역할과 책임)을 명시합니다. 에이전트끼리 서로 영역을 침범하지 않고 매끄럽게 인계하도록 돕습니다.
3.  **`user.md` (사용자 의도)**
    *   사용자의 OS, 선호하는 프로그래밍 언어, 코딩 컨벤션 및 답변 스타일을 기록합니다. 이를 통해 에이전트가 사용자의 취향에 꼭 맞춘 맞춤형 코드를 생성합니다.
4.  **`skills/` (스킬 라이브러리)**
    *   특수 작업이나 전문 영역에 필요한 상세 프로세스를 매뉴얼화한 마크다운 파일입니다. 에이전트가 필요할 때마다 이 가이드북을 꺼내어 전문가 역할을 수행할 수 있도록 합니다.

## 🚀 시작 및 설치 방법

### 1단계. 환경 파일 설정
1.  프로젝트 루트에 있는 `.env.example` 파일을 복사하여 파일명을 `.env`로 변경합니다.
2.  `.env` 파일 내에 본인의 API 키(OpenAI, Gemini, Anthropic 등)를 작성합니다.
    > ⚠️ **주의**: `.env` 파일은 절대 Git 저장소에 올리거나 남에게 노출하지 마세요. (이미 `.gitignore`에 등록되어 유출을 차단하고 있습니다.)

### 2단계. 프로필 세팅 실습
1.  `soul.md`, `agent.md`, `user.md` 파일을 열어 대괄호(`[...]`)로 감싸진 영역에 본인의 정보, 취향, 설계하고자 하는 에이전트의 성격을 자유롭게 채워 넣으세요.
2.  에이전트를 실행하거나 AI 어시스턴트 창에 이 파일들을 업로드(또는 컨텍스트 등록)하여 에이전트가 바뀐 프로필을 기반으로 소통하는지 확인합니다.

### 3단계. 스킬 작성 실습
1.  `.agents/skills/basic-harness/SKILL.md`를 읽고 스킬 파일이 작동하는 원리를 파악하세요.
2.  새로운 스킬을 추가하고 에이전트에게 해당 지식을 활용한 코딩 지시를 내려봅니다.
