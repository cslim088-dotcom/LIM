오늘의 에이전트 실습

무기고 (Arsenal) 가이드

개인 AI 에이전트를 나만의 행동강령과 전용 지식으로 무장시키고, 협업 에이전트 생태계를 구축하는 핵심 워크스페이스입니다.

👋 배포의 말씀 & 감사

본 패키지는 여러분이 인공지능을 부리는 단순 프롬프트 사용자를 넘어, 나만의 맞춤형 AI 참모진(Agent Agency)을 설계하고 지휘하는 리더로 성장하도록 돕기 위해 만들어졌습니다.

이 멋진 아키텍처의 밑바탕이 되어준 오픈소스 에이전트 하네스(Agent Harness) 시스템에 깊은 감사를 표합니다. 하네스 팀의 선구적인 설계 덕분에 개발자는 에이전트에게 상황별 전문 지식을 공급하고 안전하게 코드를 자동 생성 및 제어할 수 있게 되었습니다.

🏛️ 에이전트를 길들이는 3대 기틀 (MD 프로필)

에이전트는 단순 대화만으로 완성되지 않습니다. 워크스페이스 내에 아래의 세 가지 파일들을 적절히 설정해 두면, 에이전트가 본인의 성향과 임무에 완벽하게 적응합니다.

🎭 soul.md (에이전트의 영혼 / 행동 규칙)

에이전트가 일할 때 가질 기본 성격, 가치관, 절대 타협하지 말아야 할 규범들을 설정합니다.

  • 에이전트가 어떤 페르소나로 대화할 것인가 설정 (예: 꼼꼼한 피드백형, 간결한 실행형)
  • 오류를 발견했을 때 대처하는 태도 명시
  • 개발 시 절대 지켜야 할 우선순위 선언

👥 agent.md (동료 / 조직도)

워크스페이스 내에서 여러 에이전트가 활동할 때 서로의 역할 분담과 인계 규칙을 관리합니다.

  • 기획 사령관, 개발 사령관 등 목적에 따른 역할의 세분화
  • 작업 흐름을 인계받아 작업할 때 로그를 작성하고 동기화하는 규칙
  • API 비용 초과나 예기치 않은 위험 발생 시의 공동 대책 수립

🎯 user.md (사용자의 의도 / 코딩 컨벤션)

사용자의 OS 환경, 코딩 취향, 그리고 에이전트에게 기대하는 소통 스타일을 사전에 명시합니다.

  • Windows / macOS / Linux 등 타겟 OS의 빌드 옵션 조율
  • 선호하는 디자인 취향 (예: HSL 다크 테마, Outfit 폰트, 미려한 그라데이션)
  • 선호하는 개발 스택 및 코딩 컨벤션 (예: 카멜 케이스, 모듈형 설계)

🛠️ 전문 지식 주입장치: 스킬(Skill)

에이전트에게 "에러를 디버깅하는 방법" 또는 "특정 라이브러리를 사용해 프론트를 구성하는 방법" 등, 특정 주제에 대한 상세 지식을 공급할 때 사용하는 기능입니다.

📂 스킬 파일의 구조

스킬 파일은 최상단의 YAML Frontmatter 메타데이터와 마크다운 본문으로 나뉩니다.

---
name: python-linter
description: Python 코드 오류를 정밀 점검하고 포맷팅할 때 사용되는 스킬입니다.
---

# 🐍 Python 코드 검증 가이드
본 스킬이 트리거되면 다음 체크리스트를 준수하여 오류를 정정합니다...

에이전트는 사용자가 내린 요청 메시지를 분석한 뒤, description에 명시된 내용이 해당 작업과 어울린다고 판단하면 이 스킬 가이드를 컨텍스트에 자동으로 장착해 작업을 수행합니다.

📂 폴더 구조도

본 실습 키트는 다음 폴더 구조를 갖추어 실습하게 됩니다.

lee_main/ ├── .agents/ │ └── skills/ │ └── basic-harness/ │ └── SKILL.md (스킬 가이드) ├── .env.example (설정 예시) ├── .gitignore (깃 제외 목록) ├── README.md (안내서) ├── instruction.html (본 설명서) ├── soul.md (행동 강령 실습) ├── agent.md (조직도 실습) └── user.md (취향 등록 실습)

🚀 실습 진행 순서

1

환경 설정 하기

.env.example을 복사해 .env를 만들고 실제 API 키를 입력합니다.

2

나만의 프로필 작성

soul.md와 user.md를 수정하여 여러분과 여러분의 에이전트 정체성을 선언하세요.

3

커스텀 스킬 제작

.agents/skills/ 폴더 아래에 새 디렉토리와 SKILL.md를 만들고 에이전트에게 작업을 시켜보세요.
