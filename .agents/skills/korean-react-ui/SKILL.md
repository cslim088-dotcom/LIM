# Korean React UI Skill

이 스킬은 React, JavaScript, HTML/CSS 기반 화면을 만들거나 수정할 때 사용합니다. 목표는 사용자가 선호하는 다크 모드 감성, 읽기 쉬운 코드, 한국어 중심 커뮤니케이션을 일관되게 유지하는 것입니다.

## 1. 기본 태도

1. 답변과 작업 보고는 한국어 존댓말로 작성합니다.
2. 구현 전후로 핵심 변경점과 검증 결과를 짧게 정리합니다.
3. 불확실한 요구사항은 코드베이스의 기존 패턴을 먼저 확인한 뒤 합리적으로 결정합니다.
4. 실제 API 키, 토큰, 개인 정보가 코드에 들어가지 않도록 확인합니다.

## 2. React 구현 규칙

1. 컴포넌트 이름과 함수명은 역할이 드러나는 camelCase 또는 PascalCase를 사용합니다.
2. UI 상태는 가능한 한 명확한 이름으로 분리합니다.
3. 반복되는 UI 데이터는 배열과 map으로 정리하되, 과한 추상화는 피합니다.
4. 조건부 렌더링은 읽기 쉬운 흐름을 우선합니다.
5. 주석은 복잡한 의도나 비즈니스 규칙을 설명할 때만 짧게 남깁니다.

## 3. 디자인 규칙

1. 기본 톤은 어두운 테마를 우선하되, 한 가지 색상만 과하게 반복하지 않습니다.
2. 버튼, 카드, 입력 요소에는 hover와 transition을 적용해 부드럽게 반응하도록 만듭니다.
3. 모바일과 데스크톱에서 텍스트가 겹치거나 잘리지 않는지 확인합니다.
4. 섹션 제목, 카드 제목, 버튼 텍스트의 크기는 용도에 맞게 조절합니다.
5. 중요한 CTA는 눈에 띄게 만들되, 화면 전체를 방해하지 않게 배치합니다.

## 4. 검증 체크리스트

작업을 마친 뒤 가능한 범위에서 다음을 확인합니다.

1. `npm run lint` 또는 프로젝트가 제공하는 lint 명령이 통과하는지 확인합니다.
2. 타입스크립트 프로젝트라면 타입 검사 또는 빌드 명령을 확인합니다.
3. 주요 반응형 구간에서 레이아웃 깨짐이 없는지 확인합니다.
4. `.env`나 민감 정보가 커밋 대상에 포함되지 않았는지 확인합니다.

## 5. 사용 예시

사용자가 "React 화면을 다크 모드로 정리해줘" 또는 "이 컴포넌트를 사용자 취향에 맞게 고쳐줘"라고 요청하면 이 스킬을 적용합니다.
