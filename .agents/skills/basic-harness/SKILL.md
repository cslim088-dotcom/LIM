# 🛠️ 무기고 에이전트 스킬(Skill) 작동 매뉴얼

이 파일은 에이전트 시스템에서 **스킬(Skill) 파일**이 왜 필요하고, 어떻게 작성하고 작동하는지에 대한 교육용 명세서이자 템플릿입니다.

---

## ❓ 1. 스킬(Skill) 파일이 왜 필요한가?

에이전트는 LLM을 기반으로 동작하므로 방대한 지식을 가지고 있지만, **특정 프로젝트의 도메인 지식, 전용 코딩 컨벤션, 특수 라이브러리 사용법, 혹은 순차적인 워크플로우**를 완벽하게 기억하지 못합니다.

매번 사용자가 긴 프롬프트로 지시하는 것은 비효율적입니다. 이럴 때 **스킬 파일**을 프로젝트 폴더에 사전 배치해 두면, 에이전트가 관련 작업을 시작할 때 이 가이드라인을 스스로 로드하여 **즉각 해당 분야의 전문가 수준으로 행동**할 수 있게 됩니다.

*   **지식의 구조화**: 산만하게 흩어진 프롬프트를 모듈화하여 관리합니다.
*   **일관된 퍼포먼스**: 에이전트가 매번 동일한 고품질 코딩과 컨벤션을 준수하도록 강제합니다.
*   **컨텍스트 최적화**: 필요한 지식만 선택적으로 공급하여 API 토큰 소비량을 절약합니다.

---

## 🏗️ 2. 스킬 파일을 만드는 방법

스킬 파일은 `.md` 확장자를 사용하며 다음 3가지 핵심 규칙을 준수하여 작성합니다.

### ① YAML Frontmatter 작성 (최상단)
파일의 가장 첫 줄에 `---`로 시작하고 닫는 메타데이터 영역을 작성합니다. 여기에 에이전트가 스킬을 감지하고 활용할 수 있는 단서를 제공합니다.
```markdown
---
name: 스킬의 고유 식별자 (영문 소문자 및 하이픈)
description: 이 스킬이 언제 쓰이고 무엇을 해결하는지에 대한 요약 (에이전트가 이를 읽고 트리거 여부를 결정함)
---
```

### ② 행동 가이드 및 모범 코드 예제
에이전트가 수행할 작업에 대한 명확한 절차와 예시 코드를 상세히 작성합니다.
*   **Do's & Don'ts**: 해야 할 것과 하지 말아야 할 것 명시.
*   **구현 절차**: 단계별로 밟아야 할 개발 순서.
*   **코드 스니펫**: 모범적인 구현 템플릿 코드 제시.

### ③ 예외 처리 및 검증 지침
개발이 완료된 후 에이전트가 스스로 코드를 검증할 수 있는 테스트 스크립트나 체크리스트를 포함합니다.

---

## 🎯 3. [실습] 나만의 첫 번째 커스텀 스킬 만들기

1.  `.agents/skills/` 폴더 하위에 자신만의 주제로 폴더를 생성합니다. (예: `python-formatter`)
2.  해당 폴더 내에 `SKILL.md` 파일을 만들고 위의 Frontmatter와 가이드라인 내용을 작성합니다.
3.  에이전트를 호출하여 새롭게 만든 스킬이 잘 작동하는지 질문해 보고 테스트합니다. (예: *"python-formatter 스킬은 언제 써야 하니?"*)
